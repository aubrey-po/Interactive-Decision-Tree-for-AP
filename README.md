# Initiating Faculty Appointments and Promotions

## Overview

This interactive decision tree helps Johns Hopkins University administrative assistants navigate the faculty appointment and promotion process. Users answer a series of questions via dropdown menus to receive personalized guidance on the correct contact person and process to follow.

## Features

- **Interactive Decision Tree**: Users select from dropdown menus to answer questions about the candidate's aspirational rank and current appointment status
- **Smooth Navigation**: Seamless transitions between steps with back button support
- **Clickable Email Links**: All contact emails are clickable for easy communication
- **Progress Tracking**: Visual progress bar shows users where they are in the decision tree
- **Reset Functionality**: Users can reset and start over at any time
- **Modern Design**: Clean, professional interface using Johns Hopkins brand colors (Heritage Blue #002D72 and Crisp White #FFFFFF)
- **Responsive Layout**: Works on desktop, tablet, and mobile devices
- **Fast Loading**: Optimized for quick performance

## How to Use

1. Visit the interactive decision tree: **[https://aubrey-po.github.io/Interactive-Decision-Tree-for-AP/](https://aubrey-po.github.io/Interactive-Decision-Tree-for-AP/)**
2. Start with the initial question about the candidate's aspirational rank
3. Select your answer from the dropdown menu
4. Click "Next" to proceed
5. Answer any follow-up questions as needed
6. Receive your personalized recommendation with the contact person and next steps
7. Use the "Back" button to change your answer at any time
8. Use the "Reset" button to start over from the beginning

## Decision Tree Paths

### Initial Selection (Question 1)
Select the candidate's aspirational rank from one of these options:
- **Professor, Associate Professor, or Assistant Professor** → Direct contact recommendations
- **Research, Teaching, or Engineer/Scientist ranks** → Follow-up questions about current appointment status
- **Other specialized ranks** → SmartPath appointment requests

### Follow-Up Questions
If applicable, answer whether the candidate currently has an appointment in related ranks:
- **Yes** → Email promotion dossier to Kirstin Brooks-Robinson
- **No** → Start new appointment request in SmartPath
